# Laboratorios Windows

## Ideas de laboratorios (busca colaboradores en los issues)
- Acceso por RDP con contraseña débil y movimiento lateral con PsExec (Security.evtx, 4624/4625/7045).
- Persistencia con tareas programadas y claves Run.
- Ejecución de PowerShell ofuscado (evento 4104) y su desofuscación.
- Preparación para ransomware: borrado de shadow copies y deshabilitación de Defender.
- Análisis de memoria con Volatility 3 de un RAT común en la región.
