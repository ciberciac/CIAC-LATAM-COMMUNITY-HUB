# Laboratorios de seguridad de APIs

Basados en el **OWASP API Security Top 10 (2023)**.

## Ideas de laboratorios (busca colaboradores en los issues)
- **API1 · BOLA:** detectar en logs la enumeración de IDs de objetos ajenos.
- **API2 · Autenticación rota:** abuso de tokens JWT y relleno de credenciales.
- **API4 · Consumo de recursos sin restricción:** identificar abuso de endpoints sin límite de tasa.
- **API6 · Flujos de negocio sensibles:** automatización de compras o registros masivos.
- Análisis de logs de un API Gateway con `jq` y construcción de detecciones.

## Herramientas sugeridas
jq · OWASP crAPI (entorno vulnerable de práctica) · Postman / Bruno · Burp Suite Community · Elastic o Grafana Loki para análisis de logs
