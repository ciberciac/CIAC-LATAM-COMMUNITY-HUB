# Laboratorios Linux

## Ideas de laboratorios (busca colaboradores en los issues)
- Servidor web comprometido: análisis de logs de acceso y detección de webshell.
- Fuerza bruta SSH y persistencia con `authorized_keys` y cron.
- Criptominero en un servidor expuesto: procesos, conexiones y servicios systemd.
- Análisis de auditd para reconstruir comandos ejecutados.

## Herramientas sugeridas
auditd · journalctl · UAC (Unix-like Artifacts Collector) · Volatility 3 · plaso / log2timeline
