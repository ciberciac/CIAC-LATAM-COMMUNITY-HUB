# Madurez · Comunicaciones de Ciberseguridad y Crisis

**Modelo de referencia:** SIM3 P-2 y H-6 · NIST CSF 2.0 RS.CO · ISO 22361

La comunicación es donde muchas organizaciones fallan durante una crisis: notificaciones tardías, mensajes contradictorios o sin vocero. No existe un modelo de madurez dedicado; este dominio combina los parámetros de comunicación de **SIM3**, la categoría **RS.CO** del **NIST CSF 2.0** y la norma **ISO 22361** de gestión de crisis.
