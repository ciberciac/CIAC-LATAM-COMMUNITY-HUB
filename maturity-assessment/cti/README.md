# Madurez · Inteligencia de Amenazas (CTI)

**Modelo de referencia:** CTI-CMM

Mide el programa de inteligencia por el **valor que entrega** a otras funciones, siguiendo el enfoque del **CTI-CMM**: cada dominio del modelo representa una parte interesada (riesgos, detección, respuesta, vulnerabilidades, dirección). No hace falta llegar al máximo en todos: el nivel adecuado depende de lo que cada parte interesada necesita.
