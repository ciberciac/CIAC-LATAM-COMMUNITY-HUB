# Análisis de Hipótesis en Competencia (ACH)

Método de análisis estructurado desarrollado por Richards J. Heuer Jr. para reducir sesgos (sobre todo el de confirmación) al evaluar varias explicaciones posibles de un hecho.

## Cuándo usarlo
- Atribución de un incidente a un actor.
- Determinar si una actividad es un ataque dirigido, oportunista o un falso positivo.
- Evaluar la motivación detrás de una campaña (financiera, espionaje, hacktivismo).

## Los 8 pasos

1. **Identificar hipótesis** posibles, incluidas las incómodas. Mínimo tres.
2. **Listar evidencias y argumentos** relevantes, también la ausencia de evidencia esperada.
3. **Construir la matriz:** cada evidencia contra cada hipótesis → `C` consistente, `I` inconsistente, `N` neutral.
4. **Refinar:** eliminar evidencias sin valor diagnóstico (consistentes con todas las hipótesis).
5. **Concluir provisionalmente:** la hipótesis más probable es la que tiene **menos inconsistencias**, no la que tiene más consistencias.
6. **Analizar sensibilidad:** ¿qué pasa si una evidencia clave es falsa o engañosa?
7. **Informar** con todas las hipótesis y su probabilidad relativa.
8. **Definir indicadores** que, si aparecen, cambiarían la conclusión.
